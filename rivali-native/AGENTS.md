# Rivali native

Read matching Expo SDK 57 documentation before changing native APIs. Use Expo Router in src/app and keep services in src/lib. Install native libraries with `npx expo install`. Validate with typecheck, lint, Expo Doctor and an iOS Metro export. Custom WebRTC requires an EAS development or standalone build, not Expo Go. Preserve the approved original Rivali artwork and compact microphone; do not add Doug's portrait. Keep secrets out of EXPO_PUBLIC variables. No unverified MyChron network/flashing protocol belongs in this client. Do not edit generated ios/android folders; use config plugins.
